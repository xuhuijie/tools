税额计算

增值税四件套互算 · 劳务报酬预扣税 · 税额综合计算

输入

四件套的关系。含税价 = 不含税价 ×(1+税率)；税额 = 不含税价 × 税率；不含税价 = 含税价 ÷(1+税率)。 这里按「价外税」理解：税额本身不参与再计税，所以四个量知道任意两个就能推出另外两个。 实际开票还要区分税率与征收率、是否享受小微优惠，以税务口径为准。

输入

元

预扣预缴应纳税所得额预扣率速算扣除数税额
口径。劳务报酬（设计、咨询、讲课、演出等独立劳务）的预扣预缴规则： 每次收入不超过 4000 元的，减除费用 800 元；超过 4000 元的，减除 20% 的费用； 余额为预扣预缴应纳税所得额，再按三级超额累进预扣率（20% / 30% / 40%）预扣。 年度汇算清缴时劳务报酬并入综合所得，按 3%~45% 的年度税率表重算，与预扣数多退少补—— 所以本页给的是「预扣数」，不等于最终税负。

输入

税率表版本。综合所得用 2019 年起的七级年度税率表，月度工资按「累计预扣预缴」的精神折算成月等效表估算， 与逐月累计算出的结果在年初年末会有差异。年终奖单独计税政策目前延续至 2027 年底， 36000 / 144000 等临界点会出现「多发一元、到手变少」，本页会标出来。
全部纯本地计算；税额结论仅供参考，实际以税务机关口径与你的专项附加扣除为准
