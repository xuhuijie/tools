生成密钥对

RSA 走 forge.pki.rsa.generateKeyPair。JS 里算大素数比静态编译的 OpenSSL 慢一个量级， 就是页面会卡一会儿的原因。密钥只在内存里，刷新即消失，本页不写 localStorage。

JWT 签名校验

声明值说明

校验是认真的：先按声明里的 alg 与手选的算法比对（防止 alg 混淆攻击）， 再用 HMAC 或 RSA/ECDSA 真正验一遍签名，最后单独检查 exp / nbf / iat。 这一点和只做 Base64 解码的那种「JWT 解析」不是一回事。

所有密钥与证书都在你的浏览器里生成、解析，不上传、不写磁盘（除非你点下载）
