数独 · 舒尔特方格 · 反应速度 · CPS 手速 · 计数器 · 猜数字 · 种子转磁力

题目

题目由「随机终盘 + 挖洞」生成，并逐洞回验唯一解，所以每道题都有且只有一个答案。 检查只对比与标准解是否一致，不做「是否有解」的重复推理。

舒尔特方格

按 1 到 N 的顺序依次点击，用来练视觉搜索与注意力。点对自动进入下一个数字。

格子每次重新排布，同一个数字的位置不会重复。计时从点「开始」或点第一个数字起算。

反应速度测试

点击这里开始，变绿后立刻再点一次

平均反应时间样本越多越准；抢跑（变绿前点）那次会被判无效并重来，不计入成绩。 浏览器定时器精度约 1~4ms，加上显示器延迟，绝对值仅供参考，看相对变化更有意义。

CPS 手速测试

点击开始，然后在 5 秒内尽可能多地点击

5 秒计时窗口，统计点击次数与每秒点击（CPS）。单次点击间隔小于 15ms 会被当作连点/触屏抖动剔除， 否则长按或连发会刷出虚高结果。

计数器

0

支持键盘操作：+/↑ 增加，-/↓ 减少，0 归零，Ctrl+Z 撤销。状态记在浏览器里，刷新不丢。

数字小游戏 · 猜数字

    二分法最快：每次猜中间值，1~100 最多 7 次必中。每次都给出「大了 / 小了」与还剩下多少个可能值。

    种子转磁力链接

    磁力链接的核心是 btih：单文件种子取整个文件的 SHA-1， 多文件种子先把各文件的 路径长度 + 路径 + 长度 拼成 info 串再取 SHA-1。 本页按 bencode 自己解析种子文件，不依赖任何库，也不发网络请求。

    全部功能纯本地运行，不联网、不上传；游戏成绩只存在你自己的浏览器里
