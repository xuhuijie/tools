HTTP 状态码 · User-Agent 分析 · 端口自查清单

速查

状态码按 RFC 9110 与各扩展规范整理，共 60 余条。第 1 位定类别，后两位才是具体原因； 遇到没见过的码先看首位，比查全表快。

User-Agent

项值

识别逻辑是「按特征串匹配」，不是查库。UA 可以随便伪造，所以结果只能当线索， 不能当身份凭证——按 UA 做权限判断是常见安全漏洞。

常用端口清单与自查

关于在线扫描。浏览器里发不出 TCP 连接，纯前端**做不到**端口扫描； 用 fetch 试端口也只是发 HTTP 请求，且被 CORS 与混合内容限制，试出来的东西不可信。 所以本页不做扫描，而是给你一份「常用端口 + 危险暴露 + 对应加固命令」的清单， 配合本机 ss -lntp / netstat -ano 或服务端 nmap 使用。
状态码与端口清单为内置数据（不联网）；UA 分析纯本地字符串匹配
