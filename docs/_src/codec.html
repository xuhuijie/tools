二维码与条形码

二维码生成 · 二维码识别 · 条形码生成（Code128 / EAN / UPC 等）

内容

px
模块

编码用 qrcode-generator，按 ISO/IEC 18004 生成。容错级别越高，同样内容需要的模块越多， 但被遮挡或磨损后越容易扫出来；要往中间贴 logo 就选 H。

上传或拖入二维码图片

点击选择图片，或把图片拖到这里
PNG / JPG / WebP 均可，图片不会上传，全部在本地解码

解码用 jsQR，按 ZXing 的定位算法找三个角点。识别不出来通常是这几类原因： 二维码太小、图被压缩失真、光照不均反光、有遮挡，或图片里根本没有码。 可以把原图放大再试，本页会把定位角点画出来，方便判断是没找到码还是解码失败。

条码类型与内容

mm

编码由 bwip-js（Barcode Writer in Pure PostScript 的 JS 版）完成，输出 SVG 矢量图， 打印或放大都不糊。EAN/UPC/ITF 的校验位会自动算，输入位数不对会直接报错，不会生成一张扫不出来的图。

二维码与条形码全部在浏览器本地生成与识别，图片不上传；生成结果可用于印刷与扫码
