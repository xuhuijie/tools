短链生成

短链必须由服务端发码，本地生不出来，所以这里老实调用公开接口：is.gd / v.gd / TinyURL 均为免密钥 GET 接口。 接口挂了或断网时，「本地短参」把长 URL 压成一个可分享的短参数形式，它仍然指向原地址（不会真的变短），只做兜底不假装能发码。

robots.txt 生成器

秒

按 Robots Exclusion Protocol 生成：一组 User-agent 可挂多条规则，同一组内 Allow 先于 Disallow 输出。 $ 结尾通配与 * 通配原样保留，不做转义——robots.txt 就是按字面匹配的。

网站备案号解析与自查清单

备案信息存在工信部数据库里，没有任何公开接口能让纯前端直接查——需要备案号 + 域名 + 验证码， 还要过反爬。所以本页做的是**格式解析**：拆出省份、备案主体类型、编号、网站序号， 校验括号与后缀写法，并给出官方查询入口。不给假结果，也替你省掉手工拆解。
